# 黄绘莉律师网站高端专业化改版设计

## 改版目标

网站应呈现顶级律所律师个人页常见的克制、严谨与专业分量。页面不使用夸张头衔、虚构奖项或泛化的营销口号，也不展示执业证号。权威感来自人物呈现、业务边界、案例细节和清晰的内容秩序。

## 设计方向

整体采用“律所合伙人档案 + 争议解决案例卷宗”的混合表达：

- 以人物和专业方向建立第一印象。
- 以三类并列业务说明服务边界。
- 以五个完整案例呈现实际处理能力。
- 以简洁的律师档案和联系信息结束页面。

页面不使用奖章、法槌、天平、证书、金色渐变、大面积圆角卡片或夸张动效。颜色以骨白、墨绿黑、冷灰为主，古铜色只用于细线、编号和小范围状态信息。

## 信息结构

### 1. 首屏

- 人物照片是首屏的主要视觉内容。
- 显示姓名、专职律师、四川观今律师事务所和“民商事争议解决”定位。
- 用一段短文说明主要处理合同债权与执行、企业经营争议、婚姻家事财产争议。
- 保留电话咨询主按钮，不设置重复的次级按钮。

### 2. 业务领域

三类业务并列，不设置主次：

1. 合同债权与执行
2. 企业经营与劳动争议
3. 婚姻家事财产争议

每类业务只保留两个层次：客户通常面临的问题，以及律师能够处理的具体事项。图片作为气氛和主题提示，不承担文字说明功能。

### 3. 律师介绍

- 说明主要执业方向和处理民商事案件时的工作重点。
- 展示专职律师、执业机构、办公地点和服务阶段。
- 不展示执业证号。
- 不使用“资深”“顶级”“首席”“知名”等无法由资料支持的身份词。

### 4. 服务方式

用简洁的流程说明首次咨询、材料研判、接受委托、诉讼或仲裁、执行衔接。重点说明工作边界和信息透明，不重复业务介绍。

### 5. 代表案例

展示资料中的五个脱敏案例，每个案例采用统一字段：

- 委托背景
- 争议焦点
- 证据组织
- 程序策略
- 处理结果

案例包括：

1. 未签书面合同的买卖货款纠纷
2. 终本后追加未实缴出资股东
3. 违法解除与未签劳动合同争议
4. 合伙经营中的退伙与分红争议
5. 离婚案件中的房产与隐匿存款分割

案例事实、金额范围、处理路径和结果仅使用现有资料。页面保留脱敏与个案结果不可类推的说明。

### 6. 联系与页脚

- 联系区只显示电话、四川观今律师事务所、办公地址和咨询前建议准备的材料。
- 页脚只保留简短法律提示和版权信息。
- 全站不出现执业证号。

## 视觉与排版

- 桌面端使用大幅人物、窄栏正文、宽松节奏和细线分区。
- 标题采用具有出版感的中文衬线字体，正文使用清晰的中文无衬线字体。
- 案例区采用档案式编号和大段留白，不使用五张相同卡片。
- 深色区只用于首屏、服务流程或结尾中的一个至两个关键区域，避免全页压暗。
- 动效仅保留轻微进入和导航状态变化，并支持 reduced motion。

## 移动端

- 首屏以人物照片为主体，姓名和专业方向叠加在安全的深色渐变区域。
- 三类业务纵向排列，确保标题、问题和服务项目不挤压。
- 案例按字段纵向展开，取消复杂多栏，保证长文本阅读宽度。
- 电话咨询固定控件只在离开首屏且未进入联系区时出现。
- 不允许横向滚动、文字截断、头部遮挡或图片主体裁切。

## 验收标准

- 页面源代码、结构化数据和可见文字中均不出现执业证号。
- 五个案例均包含五个统一字段，并与源资料一致。
- 桌面端与 360 像素宽移动端均无横向溢出。
- 键盘导航、焦点状态、语义标题和对比度满足基本可访问性要求。
- 无 JavaScript 时，主要内容、案例和联系方式仍可阅读。
- 正式域名与 `www` 域名部署后均可通过 HTTPS 访问。
