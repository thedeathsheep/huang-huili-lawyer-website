# 黄绘莉律师个人网站

这是一个无需安装依赖、无需构建工具即可运行的响应式静态网站。所有样式、脚本和本地视觉资产均保存在项目内，没有第三方 CDN、字体、统计代码或图片热链。首页与律师简介已接入黄绘莉律师职业形象照，咨询区继续使用不代表真实办公环境的中性空间视觉。

## 文件结构

```text
黄绘莉律师个人网站/
├─ index.html                    页面内容、SEO 与结构化数据
├─ styles.css                   响应式视觉样式
├─ script.js                    移动导航、案例、滚动与 FAQ 交互
├─ robots.txt                   搜索引擎抓取基础规则
├─ README.md                    使用与上线说明
└─ assets/
   ├─ huang-huili-portrait.webp 首页职业半身照（1600×2000）
   ├─ huang-huili-profile.webp  简介区职业形象照（1200×1500）
   ├─ consultation-placeholder.svg  空置会议空间视觉
   ├─ qr-placeholder.svg        预留二维码文件（当前页面不展示）
   ├─ favicon.svg               浏览器图标
   └─ og-cover.svg              社交分享封面
```

## 打开网站

可以直接双击 `index.html` 预览。建议使用本地服务器，以便按照接近正式部署的方式检查：

```powershell
python -m http.server 8080 --directory "C:\Users\whatk\Downloads\黄绘莉律师个人网站"
```

然后访问：

```text
http://localhost:8080/
```

## 图片资产

首页与“关于律师”区已经接入用户提供并确认用于本项目的职业形象照。公开站点使用的是重新裁切、压缩且不携带原始 EXIF 元数据的 WebP 文件，原始图片未写入项目仓库。

| 用途 | 当前文件 | 尺寸 | 页面语义与构图 |

| 关于律师 | `assets/huang-huili-profile.webp` | 1200×1500 | 4:5 较紧凑构图，使用 `alt="黄绘莉律师职业形象照"` |

| 浏览器图标 | `assets/favicon.svg` | 64×64 | 石墨黑、象牙白与香槟金字标 |
| 分享封面 | `assets/og-cover.svg` | 1200×630 | 编辑式品牌封面，不使用人物图像 |

两张人物 WebP 均控制在 300KB 以内。后续如更换照片，可保持当前文件名直接覆盖，也可以将新文件放入 `assets` 后同步修改 `index.html` 中的 `src`、实际 `width`、`height` 和准确的替代文本。人物图片必须确认身份、使用授权和公开发布范围；中性空间图仍应使用空 `alt=""`。

页面当前不展示假二维码。`assets/qr-placeholder.svg` 仅作为预留文件保留，不应接入页面；收到真实、可扫描且确认指向正确联系方式的二维码后，再修改页面完成接入。分享封面如改为 JPG 或 PNG，需同步修改 `og:image` 路径与类型。

## 正式上线前必须复核

1. **执业信息**：姓名、执业证号、律所全称、地址和电话须由律师本人逐项确认。
2. **案例资料**：五个案例须确认均为真实承办或参与案件，并再次检查脱敏程度与发布授权。
3. **宣传文案**：建议由律师本人及律所按照当前适用的律师业务推广规范进行最终审核。
4. **人物图片与替代文本**：当前已接入职业形象照；正式上线前仍须由律师本人确认照片身份、使用授权、公开发布范围和各视口裁切，人物 `alt` 必须与实际图像一致，中性空间图不得标注为律师照片。
5. **二维码**：保持页面不展示假二维码；真实二维码到位后再接入，并用多台设备测试扫描结果、目标账号和有效期。
6. **域名与备案**：确定域名后补充 canonical、正式 Open Graph 地址、ICP备案号；按实际部署情况办理相关备案。
7. **隐私政策**：当前网站没有表单、统计、在线客服或第三方地图，不主动收集访问者信息。未来如增加此类功能，应同步增加隐私政策、明示同意和相应安全措施。
8. **普法文章**：栏目目前明确标注“筹备中”，正式发布时需制作文章正文或独立详情页。
9. **分享封面**：检查 1200×630 尺寸、文字安全区和平台预览；域名确定后，将 `og:image` 改为可公开访问的绝对 URL。
10. **本地资源与兼容性**：确认所有图片、图标和脚本均能从生产路径加载，并在主流桌面与移动浏览器复核布局、对比度和焦点状态。

## 部署建议

整个目录可以直接上传到静态服务器、对象存储静态网站、GitHub Pages、Cloudflare Pages、Netlify 或常规虚拟主机。若部署在中国大陆服务器，请先确认域名与备案要求。

域名确定后建议另行生成：

- `sitemap.xml`
- 正式 canonical URL
- 绝对地址的 Open Graph 图片
- 生产环境安全响应头
- 404 页面

## 浏览器支持

推荐最新版 Chrome、Edge、Firefox 和 Safari。页面使用渐进增强：即使 JavaScript 被禁用，主要内容、FAQ 和案例文字仍可阅读；移动菜单和案例折叠等增强交互需要 JavaScript。
