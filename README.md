# 黄绘莉律师个人网站

这是一个无需安装依赖或构建工具即可运行的响应式静态网站。页面、样式、交互与视觉资产全部保存在项目内，不使用第三方 CDN、在线字体、统计代码或图片热链。

第四轮采用“证据轴”编辑档案式单页：以人物定位开场，依次呈现执业事实、业务范围、办案方法、案例、律师本人、专业观点和咨询行动。主内容约 2,301 个语义字符，浏览器默认可见约 1,796 个；通过不同 section 构图和 12／8／4 栏网格建立层级，而不是依赖卡片堆叠。


## 本地打开

可直接双击 `index.html` 预览。建议启动本地服务器，以接近正式部署的方式检查：

```powershell
python -m http.server 8080 --directory "C:\Users\whatk\Downloads\黄绘莉律师个人网站"
```

访问：

```text
http://localhost:8080/
```

## 信息架构

页面包含 8 个主 section：

1. **首页**：人物定位、单一电话行动、职业写真与四项执业凭据
2. **业务范围**：左侧问题目录与 3 个问题群、7 项业务
3. **办案方法**：深色主张与还原事实、建立证据结构、比较路径、推进节点四步
4. **办案案例**：1 个常显主档案与 4 个可折叠单列案例索引
5. **关于律师**：标题、第二张职业写真、业务概况与律师观点
6. **实务提示**：1 篇主文与 2 篇辅助提示，全部直接可读
7. **咨询须知**：3 个原生 `<details>` 问答
8. **联系咨询**：电话、律所、地址与执业证号，并与页脚组成连续深色终点

7 项业务名称为：

- 民商事合同纠纷
- 债权债务与民间借贷
- 强制执行与执行异议
- 企业法律顾问
- 企业股权与商事争议
- 劳动争议
- 婚姻家事财产争议

案例只能使用页面当前五个既有案例。维护时不得虚构案号、法院、当事人、金额、时间或办理细节；每案应继续保留初始处境、办案难点、证据与处理路径、既有结果四类信息。

## 视觉系统

品牌色：

- 石墨黑 `#171B1A`：主文字与深色平面
- 象牙白 `#F4F2ED`：主要纸面
- 香槟金 `#B4A078`：证据轴和规则线
- 深金文字 `#806A43`：浅底小号语义文字
- 灰绿色 `#69736F`：辅助信息

首页人物左缘的香槟金细线是全站唯一明显的 signature element。Services、Philosophy、Cases、About、Insights、FAQ 与 Contact 使用不同版面原型；除主案例和主 Insight 外，不依赖大面积卡片或阴影制造层级。

响应式断点：

- `≥1120px`：12 栏桌面，Hero 7＋5、Services 3＋9、Philosophy 5＋7、About 5＋7、Insights 7＋5
- `901–1119px`：紧凑桌面，导航在 1080px 切换为抽屉
- `701–900px`：8 栏平板，Hero 标题满栏，正文与人物 4＋4，Trust 固定 2×2
- `≤700px`：4 栏手机，按真实 DOM 顺序重排内容，Trust 仍为 2×2
- `≤380px`：只收紧边距、标题和电话，不改变页面结构

## 图片资产

首页和“关于律师”使用两张不同构图的职业写真。公开仓库只保存经过裁切、压缩且不携带 EXIF 元数据的 WebP 文件，生成源图不写入项目。

| 用途 | 文件 | 尺寸 | 页面语义 |
|---|---|---:|---|
| 首页主视觉 | `assets/huang-huili-portrait.webp` | 1600×2000 | `alt="黄绘莉律师站姿职业写真"` |
| 关于律师 | `assets/huang-huili-profile.webp` | 1200×1500 | `alt="黄绘莉律师坐姿办公职业写真"` |
| 浏览器图标 | `assets/favicon.svg` | 64×64 | 石墨、象牙白与香槟金字标 |
| 分享封面 | `assets/og-cover.svg` | 1200×630 | 平面深色块、规则线与金色证据轴 |

后续替换写真时，应同步核对文件名、实际 `width`／`height`、准确的替代文本、人物身份一致性、生成或使用授权及公开发布范围。

页面不展示微信或二维码入口。只有取得真实、可扫描且确认指向正确联系方式的二维码后，才可新增相关模块；`qr-placeholder.svg` 不能作为公开二维码使用。

## 交互与渐进增强

`script.js` 提供：

- 移动抽屉导航、遮罩关闭、Escape、Tab 焦点约束与焦点恢复
- 滚动导航高亮与上下文返回顶部
- Hero 完全滚过后、Contact 尚未进入时才显示的手机固定电话栏
- Reveal 进入动画及 `prefers-reduced-motion` 降级
- 4 个辅助案例展开与收起
- FAQ 单项展开增强
- 锚点滚动与当前年份

浮动电话栏仅在视口不超过 700px、Hero 已滚过、Contact 尚未进入且菜单关闭时可见；返回顶部约在滚动 2.25 个视口后出现。两者在 Contact、Footer 或移动菜单打开时隐藏，并同步更新 `aria-hidden` 与 Tab 顺序。

禁用 JavaScript 后，主导航仍可用，固定电话栏保持隐藏，5 个案例详情、3 篇实务提示与 FAQ 均可阅读。打印时所有案例详情强制显示，深色区域转为清晰浅底，菜单和浮动控件隐藏。

## 发布前内部核验

以下是维护者核验清单，不应复制到访客页面：

1. **执业信息**：姓名、执业证号、律所全称、地址和电话由律师本人逐项确认。
2. **案例资料**：五个案例确认真实承办或参与情况，并检查脱敏程度与发布授权。
3. **宣传文案**：由律师本人及律所按届时适用的律师业务推广规范审核，不作胜诉、执行、回款或其他结果承诺。
4. **人物图片**：确认身份一致性、生成与使用授权、公开范围、画面真实性边界和各视口裁切。
5. **二维码**：没有真实二维码时保持页面不展示；接入后跨设备核对目标账号和有效性。
6. **域名与备案**：取得真实域名后再增加 canonical、绝对 Open Graph 地址、Sitemap 和实际备案号，不生成虚假字段。
7. **隐私规则**：当前无表单、统计、在线客服或第三方地图；未来新增相关功能时同步完善隐私与安全措施。
8. **分享封面**：检查 1200×630 尺寸和常用平台预览；生产域名确定后将 `og:image` 改为公开可访问的绝对 URL。

## 浏览器与视觉验收

推荐最新版 Chrome、Edge、Firefox 和 Safari。回归矩阵覆盖：

- 1440×1000
- 1024×768
- 900×1200
- 768×1024
- 390×844
- 367×812
- 360×800
- 320×568
- 844×390 横屏

自动检查应覆盖结构数量、七项业务、五案四字段与核心事实、语义字符预算、网络与外部资源、横向溢出、ARIA、移动导航、案例与 FAQ、无 JavaScript、Reduced Motion、打印和浮动控件状态。

自动测试全绿不能替代人工视觉验收。每次发布前还应逐段查看核心视口截图，确认：H1 是唯一主导信息；Hero 人物与证据轴清楚；各 section 职责和构图可一眼区分；平板与手机不是桌面版机械压缩；Contact 与 Footer 形成连续终点；有效事实没有因追求简洁而丢失。

建议页面高度上限：

- 1440×1000：约 7,000px
- 390×844：约 10,200px
- 320×568：约 11,500px

不得通过缩小正文或删除必要事实换取高度达标。

## 部署

整个目录可直接上传到静态服务器、对象存储静态网站、GitHub Pages、Cloudflare Pages、Netlify 或常规虚拟主机。若部署在中国大陆服务器，应根据真实域名和服务器情况办理备案。

真实域名确定后再增加：

- `sitemap.xml`
- canonical URL
- 绝对地址的 Open Graph 图片
- 生产环境安全响应头
- 404 页面
