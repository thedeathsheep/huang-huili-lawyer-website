# 黄绘莉律师个人网站

一个无需构建工具即可运行的响应式静态网站。页面、样式、交互和图片全部保存在项目内，不依赖在线字体、第三方图片热链或统计脚本。

当前版本采用“律师个人档案 + 案件处理记录”的结构。页面以人物和专业方向开场，三类业务并列呈现，五个脱敏案例完整说明委托背景、争议焦点、证据组织、程序策略和处理结果。

## 本地预览

在项目目录启动静态服务器：

```powershell
python -m http.server 8081
```

访问 `http://localhost:8081/`。

## 页面结构

页面按客户浏览顺序分为六部分：

1. 首页：人物、姓名、律所、专业定位和电话入口
2. 业务领域：合同债权与执行、企业经营与劳动争议、婚姻家事财产争议
3. 关于律师：专业方向、工作方法和必要执业信息
4. 服务方式：电话沟通、审查材料、签订委托、裁判后事务
5. 代表案例：五个完整的脱敏案件处理记录
6. 联系咨询：电话、律所、地址和咨询前材料提示

三类业务在视觉和内容上保持同一层级，不设置主次。案例区只使用已经确认的五个案例，不增加无法由资料支持的法院、案号、客户身份、精确日期、荣誉或职业年限。

## 文案风格

页面文案采用短句与法律常用表达，介于口语与公文之间：不用「厘清」「研判」等空话，也不使用「藏了钱」「谈不拢」等过于随意的说法。业务区用「典型情形」和「办理事项」两层对照；案例摘要写办案结果，正文保留五个字段。

新手律师不宜虚构执业年限或头衔。简介以执业机构、领域、服务阶段为锚，案例细节承担专业分量。页脚免责声明一行说完。

## 案例维护规则

每个案例必须保留以下五个字段：

- 委托背景
- 争议焦点
- 证据组织
- 程序策略
- 处理结果

修改案例时应继续隐去当事人身份和其他识别信息。过往结果仅用于说明个案中的工作内容，不能写成对同类案件的结果承诺。

## 视觉系统

主要颜色：

- 墨绿黑 `#0E1713`
- 冷白 `#F4F5F1`
- 明亮表面 `#FBFCF9`
- 冷灰绿 `#E8ECE8`
- 深古铜 `#796349`
- 浅古铜 `#C5B79C`

标题使用系统中文衬线字体，正文使用系统中文无衬线字体。页面依靠人物摄影、字号、留白和细线建立层级，不使用大面积圆角卡片、重阴影、法律符号或装饰性金色渐变。

## 分享封面

`og:image` 指向 `assets/og-cover.png` 的绝对地址。微信、QQ 和多数社交平台不解析 SVG，因此页面引用位图，`assets/og-cover.svg` 作为设计源文件保留。

修改文字或配色后，从 SVG 重新导出同名 PNG，尺寸保持 1200×630：标题使用宋体族衬线字体，副标题同族常规字重，眉标使用无衬线字体。导出后确认 `og:image:width`、`og:image:height` 与实际文件一致。

## 交互与渐进增强

`script.js` 提供：

- 移动导航、Escape 关闭、Tab 焦点约束与焦点恢复
- 滚动导航高亮
- 离开首页后显示的手机电话入口
- 返回顶部控件
- 轻微进入动效和 reduced motion 降级
- 锚点滚动与当前年份

主要内容不依赖 JavaScript。禁用 JavaScript 后，业务、律师介绍、服务流程、五个案例和联系方式仍可阅读。

## 公开信息边界

公开页面只保留姓名、专职律师身份、四川观今律师事务所、办公地址、联系电话和业务方向。个人执业编号类字段不进入可见页面、元数据、结构化数据或维护模板。

发布前应由律师本人或律所复核：

1. 姓名、律所、地址和电话是否准确
2. 五个案例是否真实、脱敏充分并具备发布条件
3. 文案是否符合届时适用的律师业务推广规范
4. 人物与业务图片是否具有公开使用权
5. 页面是否仍未加入未经确认的奖项、头衔、年限或结果承诺

## 测试与验收

运行结构测试：

```powershell
python -m unittest discover -s tests -v
```

发布前至少检查：

- 1440×1000 桌面视口
- 768×1024 平板视口
- 360×800 手机视口
- 320×568 小屏手机视口
- 键盘导航和可见焦点
- reduced motion
- 禁用 JavaScript 后的内容可读性
- 横向溢出、控制台错误和图片加载
- 自动无障碍扫描

## 部署

项目部署在 EdgeOne Pages，正式域名为：

- `https://黄绘莉律师.com/`
- `https://www.黄绘莉律师.com/`

中文域名在配置文件和绝对地址中使用 punycode 形式 `xn--etto7a200ej6d294b.com`。`index.html` 的 `canonical`、`og:url` 和 `og:image` 均指向该根域名，更换域名时需同步修改这三处。

生产目录只包含 `index.html`、`styles.css`、`script.js`、`robots.txt` 和 `assets/`。测试、设计资料、部署脚本和源文档不进入公开目录。
