# 黄绘莉律师个人网站

这是一个无需安装依赖、无需构建工具即可运行的响应式静态网站。所有样式、脚本和视觉资产均保存在项目内，没有第三方 CDN、在线字体、统计代码或图片热链。

网站围绕黄绘莉律师个人品牌组织内容：首页先说明主要问题与咨询入口，随后以 3 个问题群覆盖 7 项业务，以 4 个步骤说明办案方法，以 1 个主案例和 4 个辅助案例呈现处理思路，并提供 3 篇可直接阅读的实务提示。公开页面不展示假二维码、微信空入口、内容预告、备案占位或其他施工状态。

## 文件结构

```text
黄绘莉律师个人网站/

├─ robots.txt                   搜索引擎抓取基础规则

└─ assets/
   ├─ huang-huili-portrait.webp 首页站姿职业写真（1600×2000）
   ├─ huang-huili-profile.webp  简介区坐姿职业写真（1200×1500）
   ├─ consultation-placeholder.svg  旧版会议空间资产，公开页面不引用
   ├─ qr-placeholder.svg        内部预留文件，公开页面不引用
   ├─ favicon.svg               浏览器图标
   └─ og-cover.svg              社交分享封面
```

## 打开网站

可以直接双击 `index.html` 预览。建议使用本地服务器，以便按照接近正式部署的方式检查：

```powershell
python -m http.server 8080 --directory "C:\Users\whatk\Downloads\黄绘莉律师个人网站"
```

然后访问：

```text
http://localhost:8080/
```

## 图片资产

首页与“关于律师”区使用用户生成并提供的两张不同构图职业写真。公开站点只保留经过裁切、压缩且不携带 EXIF 元数据的 WebP 文件，生成源图未写入项目仓库。

| 用途 | 当前文件 | 尺寸 | 页面语义与构图 |
|---|---|---:|---|
| 首页主视觉 | `assets/huang-huili-portrait.webp` | 1600×2000 | 4:5 站姿三分之二身构图，使用 `alt="黄绘莉律师站姿职业写真"` |
| 关于律师 | `assets/huang-huili-profile.webp` | 1200×1500 | 4:5 坐姿办公场景构图，使用 `alt="黄绘莉律师坐姿办公职业写真"` |
| 旧版会议空间 | `assets/consultation-placeholder.svg` | 1600×1000 | 保留在仓库但公开页面不引用 |
| 微信二维码 | `assets/qr-placeholder.svg` | 800×800 | 仅为内部预留，公开页面不引用、不可作为真实二维码使用 |
| 浏览器图标 | `assets/favicon.svg` | 64×64 | 石墨黑、象牙白与香槟金字标 |
| 分享封面 | `assets/og-cover.svg` | 1200×630 | 成都民商事争议解决定位的编辑式品牌封面 |

两张人物 WebP 均控制在 300KB 以内。后续如更换写真，可保持当前文件名直接覆盖，也可以将新文件放入 `assets` 后同步修改 `index.html` 中的 `src`、实际 `width`、`height` 和准确的替代文本。人物图片必须确认身份一致性、生成或使用授权及公开发布范围。

页面当前不展示微信或二维码入口。只有取得真实、可扫描且确认指向正确联系方式的二维码后，才应在页面中新增入口，并用多台设备核对扫描结果、目标账号和有效性。

## 内部发布核验

以下为网站维护者的内部核验清单，不应复制到访客页面：

1. **执业信息**：姓名、执业证号、律所全称、地址和电话由律师本人逐项确认。
2. **案例资料**：五个案例均确认真实承办或参与情况，并检查脱敏程度与发布授权。
3. **宣传文案**：由律师本人及律所按照届时适用的律师业务推广规范审核。
4. **人物图片与替代文本**：确认人物身份一致性、生成与使用授权、公开范围、画面真实性边界和各视口裁切。
5. **二维码**：没有真实二维码时保持页面不展示；接入后核对目标账号和有效性。
6. **域名与备案**：取得真实域名后再补充 canonical、正式 Open Graph 地址、Sitemap 和实际备案号，不生成虚假字段。
7. **隐私政策**：当前无表单、统计、在线客服或第三方地图，不主动收集访问者信息；未来增加相关功能时同步完善隐私规则和安全措施。
8. **分享封面**：检查 1200×630 尺寸、文字安全区及常用平台预览；生产域名确定后将 `og:image` 改为公开可访问的绝对 URL。
9. **兼容性**：确认图片、图标和脚本均从生产路径加载，并在主流桌面与移动浏览器核对布局、对比度和焦点状态。

## 交互与渐进增强

`script.js` 提供：

- 移动抽屉导航、遮罩关闭、Escape、Tab 焦点约束与焦点恢复
- 滚动导航高亮与返回顶部
- Reveal 进入动画及 `prefers-reduced-motion` 降级
- 4 个辅助案例展开与收起
- FAQ 单项展开
- 锚点滚动与当前年份

即使 JavaScript 被禁用，主要内容、5 个案例详情、3 篇实务提示和 FAQ 仍可阅读；移动导航会改为普通换行链接。

## 部署建议

整个目录可直接上传到静态服务器、对象存储静态网站、GitHub Pages、Cloudflare Pages、Netlify 或常规虚拟主机。若部署在中国大陆服务器，请根据实际域名和服务器情况办理相关备案。

真实域名确定后再增加：

- `sitemap.xml`
- canonical URL
- 绝对地址的 Open Graph 图片
- 生产环境安全响应头
- 404 页面
